只去饱和度仍为 P99 8.703ms，不能独立达标。模糊减半可将 P99 降至 6.911ms，但有 7 个稳态 Raster 超预算帧；本轮已有单元素方案，无需再降低全部固定控件模糊。聊天是独立场景，只报告自身结果，不用聊天与计划卡之间的差异推导玻璃收益。

建议条静态格的 UI 线程仍有 **2/3603（0.0555%）** 超预算，最差 9.308ms；聊天 UI 线程超预算 0/3616。不能称为“整体完全无掉帧”。P90/P99 是直方图上界估计，超预算是引擎线程耗时超过 1000/Hz 的计数，不等于屏幕实际丢帧率。每格仅一遍且顺序固定，结论适用于本次同机、同场景、深色条件；没有更深层 GPU/滤镜/着色器归因或全机型、浅色达标证据。

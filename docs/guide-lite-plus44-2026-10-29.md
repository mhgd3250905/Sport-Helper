## 静态列表与播放生命周期

页面按轻量行模型使用 `ListView.builder`，每张动作卡独立 `RepaintBoundary`。打开页面和普通滚动只构建图片，不挂载视频组件、不创建视频控制器、不启动正常素材的准备过程。219 个正式动作使用已有 SDK WebP 首帧；旧动作继续使用既有首帧/封面。图片按显示宽乘设备像素比设置 `cacheWidth`。

点击才申请页面唯一的预览名额。透明素材使用 SDK 公开的 `UgkPackedAlphaVideo.source` 与宿主拥有的 `DrillMediaController`；旧普通 MP4 使用公开 `DrillMediaView` 与只读播放句柄。沿用 SDK 的静音循环及透明合成能力，没有复制播放器、导入 SDK 私有 State 或更改训练计时。这里的控制器是既有 SDK 控制器，不另引入 `video_player` 取代透明播放器。

切换动作先暂停、释放旧控制器并卸载旧媒体，再挂载新媒体；被释放卡片立刻恢复首帧，没有反向淡入。仅在 SDK 已 ready、有实际首帧且读取到视频位置大于 0 后，外层首帧以 200ms easeOutCubic 淡出。点暂停可保留一个暂停实例，再点继续。可见媒体面积低于 20%、退出、进入训练或应用离开前台时释放预览。异步准备和位置回调都须仍属于当前动作，避免快速切换后恢复旧播放。

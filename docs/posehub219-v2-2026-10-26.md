## 接入结果与安装方式

浏览数据直接来自 `PoseHubActionLibrary.load()` 的 `allActions`；现发布版本为 219 项。浏览、搜索、完整／待补筛选、详情与单练使用 SDK `PoseHubActionBrowser` 和 `PoseHubSinglePracticePage`，由 `SmartFitTrainerTheme` 映射 App 浅深 token。

AI 及多动作计划只接 SDK `toAiCatalog()` 返回的投影，现为 211 项；执行库与其 ID 集合相等。SDK 返回的 8 个 pending 只用于浏览和自主单练，显示“训练说明待补”，不生成训练剂量。产品不写死动作数量或待补名单。

新增完整动作的媒体 `rhythm` 包装不是训练节奏。明确的 execution 才能用于节奏；未知 execution 使用自数次数或已有时间剂量，不拿视频循环推导 cadence，原 canonical 的训练节奏保留。AI 原始 catalog、剂量、范围及未知字段保留 SDK 原对象。

完整不可变 ZIP 仅随 internal flavor APK 提供，不进入普通 Git。构建 helper 在出包前校验并要求本地恢复该正式 ZIP。第一次浏览、读取封面或播放时，Android 后台流式核验与解压到 App 私有版本目录；Dart 不把 600MB ZIP 载入内存，首页不等待解压。准备失败可重试，已发布目录和用户训练数据不覆盖。符合哈希的旧 v1 媒体可复用；没有在线或分层下载。

旧 `assets/app_test_pack/app-test-pack-r1` 的 12 组随包媒体已从本候选删除。新内测模式不创建旧版媒体下载 repository，不回退旧素材。库、单练、AI 计划视频、计划卡图片与训练下一动作缩略图均从同一安装目录读取；逻辑图片键经 `PoseHubAssetBundle` 解析，封面不冒充视频帧零。production flavor 不开启新动作库、安装桥或素材资产。

## 已发现的边界

- SDK 浏览／详情／单练 API 没有 App 问题标记扩展插槽，这些 SDK 页面不显示旧自绘目录的标记按钮。App 原训练页与动作详情保留标记能力。
- SDK pack 媒体没有原位置快照接口。标记只绑定实际动作 ID，时间戳不可用时明确记录不可用，不虚构播放位置。
- 单练按 SDK 的手动开始、暂停、结束记录实际用时；待补动作没有自动目标或默认参数。

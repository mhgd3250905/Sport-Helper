# SmartFit 手机八格 Raster 分析（2026-10-23）

本轮同场景对照把计划卡持续超预算的主要开销定位到 **App 玻璃渲染路径**。保持星尘状态不变，关闭玻璃后计划卡稳态 Raster 平均降低 69.21% / 71.79%，超预算比例由 74.02% / 74.91% 降至本轮观测的 0%。关闭星尘没有解决玻璃开启时的超预算。

这是同一构建的开关实验，不是已完成优化的前后验收。玻璃开关同时替换表面、移除背景捕获边界，尚不能区分模糊、饱和度过滤、边界或多表面合成各自的责任。本次只保存数据和分析，没有修改 App、SDK、视觉或生产默认值，没有合入 main 或推送。

## 下一步修复与验收边界

优先围绕 App 计划卡玻璃路径做拆分对照：保持同一质量与内容，逐项分离 blur、饱和度过滤和背景源边界。仅在同场景结果确认后选择缩小过滤范围、调整捕获策略或绘制边界；不因为源码可疑就直接加 RepaintBoundary，也不先改粒子数。涉及外观差异的方案继续通过内测开关和截图供开哥选择，不直接关闭生产玻璃。

本轮按固定顺序先采玻璃开、后采玻璃关，只做了一轮，没有温度、GPU 频率或 Timeline；建议下一轮反序重复验证，避免将热状态/运行时间差异当成精确收益。当前证据限于这台手机、120Hz、浅色、Impeller/Vulkan、minimal、上述两种固定内容。不与 +16 未知玻璃质量和不同聊天内容的日志拼成修复前后，不推广到深色、其他设备或 renderer。

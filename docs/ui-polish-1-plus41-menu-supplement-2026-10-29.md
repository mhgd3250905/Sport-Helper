# +41 菜单体验补项

本轮保持 `codex/ui-polish-1`、`0.1.0+41`、internal arm64原生构建号2041，在 `d6bd79cd8dc6c5439f67779bd6e894af7981faa3` 上继续。交付目录为 `../../deliveries/ui-polish-1-plus41-supplement/`。此前 +41 的APK、测试和截图均保留。

## 实际范围

菜单改为独立 `ChatComposerDock`，同一 AnimationController 使用240ms、展开easeOutCubic/收起easeInCubic。面板以ClipRect、SizeTransition(axisAlignment:-1)、FadeTransition和下方8px位移展开，输入框通过Column自然跟随高度，不另做位移动画。面板固定高度由既有四入口、主题字号和视口配置计算，动画不测量面板。

键盘和菜单共用底部占位。已弹键盘切换菜单时使用最近一次真实键盘高度，反向交换保持同高占位，避免把两者高度相加。若新IME更矮或没有IME，继续复用同一240ms控制器平滑回收剩余空白，消除旧高度永久残留和100px硬跳；不再使用超时后直接清空占位。减少动态效果时立即切换，并在构建结束后安全通知兄弟视口。

主页不再测量整个dock并逐帧setState。对话与输入区各自有独立RepaintBoundary；ValueListenableBuilder缓存消息子树，只调整局部反向列表视口，保持贴底和既有消息状态。视口仍从屏幕y=0起，透明状态栏下真实气泡的像素验证继续保留。列表局部布局仍会随可视高度变化，软件测试不据此推断设备帧耗时。

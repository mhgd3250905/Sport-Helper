## 1. 本版本的范围

本次候选保留已验收版本的原有对话首页、动作库、计划、本地规则回退、跟练和设置，无需注册账号。原有 AI 入口、引导与 AI 记忆设置仍可见；由于本次没有注入 API Key，不会启用联网 AI 请求。界面中某些联网路径可能不可用，本次不重设计这些入口。没有接入广告、行为统计或远程崩溃上报服务；如以后启用其他联网功能，将重新核对对应的数据说明。

## 2. 设备上的应用记录

为提供功能，App 在应用专用存储中保存：

| 数据 | 用途 |
|---|---|
| 训练计划及上次计划 | 再次打开或继续使用已有计划 |
| 训练名称、时间、时长、动作完成数量和训练会话结果 | 在当前设备展示最近训练及完成情况 |
| 安全确认是否完成、是否暂时限制训练两个状态 | 在未完成确认或存在风险时限制训练入口 |
| 近期对话、训练条件及安全确认问答/选择 | 保留原有对话上下文和本地规则交互，安全问答可能随近期对话保存 |
| 随机生成并保存在本机的设备 UUID | 原有 AI 请求身份功能；本次无 key 不通过 AI 请求发送 |
| AI 记忆开关及已有本地记忆 | 保留原有记忆设置；无 key 时不会通过 AI 请求外传，可在设置关闭或清除记忆 |
| 主题、语音、提示音等偏好 | 保持使用设置 |
| 内置素材及本地播放缓存 | 显示和播放动作示范 |

安全对话会询问孕产、近期手术或运动限制、急性伤痛及心血管相关风险。除了保存确认/限制训练状态，原版对话记录还可能保留题目及你选择的答案，不能理解为“只存两个布尔值”。本次未启用 AI 请求；这些本地记录仍可能进入下述系统备份或迁移范围。

App 不通过相机、麦克风、定位、健康平台或人体传感器收集动作或健康测量值，不提供自动姿势识别。动作完成结果来自训练播放器的本地流程。

## 3. 网络与第三方组件

本次候选不注入 API Key。原代码内的公开 AI 服务地址、入口和设置保持原样；公开地址不是密钥，但没有有效 key 时不会创建联网 AI 请求。动作视频通过设备内 `127.0.0.1` / `localhost` 回环服务交给系统 WebView 播放，这些回环请求本身不向互联网发送训练记录。

部分动作示范已内置，其他示范可从 `https://smartfit-media.pages.dev/v0.3.0-app/` 对应的 Cloudflare HTTPS 分发源按需下载，并按文件长度与 SHA 校验后使用。请求会向网络服务披露 IP 地址、请求时间、素材路径及 User-Agent 等普通 HTTP 元数据；素材路径可能包含动作标识，因此服务可知请求了哪段示范。App 不在这些素材请求中附加设备 UUID、聊天、安全确认回答、完整计划/训练记录或 AI 记忆。系统网络栈也可能发送其正常协议元数据。

Cloudflare 可能为内容分发、缓存、安全、防滥用及服务运行处理或保留网络数据，具体处理依其服务与隐私规则而定；我们不承诺不存在访问日志、所有请求数据都只在内存短暂处理，或未核实的固定保留天数。公开政策/支持页面同样托管于 Cloudflare，访问这些页面会产生普通网站请求。详见 [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)。这些网络数据对应内容分发功能与防欺诈、安全、合规用途；我们不利用IP推导你的位置。

App 使用 Flutter、系统 WebView、UGK 训练组件、本地偏好存储及音频组件。候选构建不含广告或第三方行为统计 SDK。本次保留原版 Android 默认备份设置：系统可按照 Android 版本、用户设置、账户和设备厂商规则，将符合条件的本地偏好及应用数据备份到用户的系统备份服务，或在设备之间迁移。相关数据可能离开当前设备，不能承诺“永不离开设备”或“系统备份已关闭”。平台备份的加密、保留、恢复和删除由对应系统服务规则管理。

## 4. 使用、分享和出售

App 的应用记录用于原有对话、计划、训练、历史、安全限制及设置。本次没有启用向 AI 服务发送这些记录的请求，也不出售这些记录。Cloudflare 素材和政策网页请求会产生上节说明的网络数据；系统备份或设备迁移也可能传输应用数据。不能仅因 API Key 为空，就把一切数据处理描述为绝对无外传。

如果你主动通过邮箱联系支持，我们会使用你自愿提供的邮箱、消息及附件处理该问题。请勿发送密码、密钥或不必要的健康资料。支持沟通是你主动发起的外部邮件，不是 App 自动上传；处理完问题后可通过同一邮箱申请删除支持邮件中由你提供的资料，但法律或必要的安全记录保留要求可能适用。

## 5. 权限

`INTERNET` 用于本机回环媒体服务、HTTPS 素材下载和公开政策页；`ACCESS_NETWORK_STATE` 用于下载组件了解网络状态与 Wi-Fi 策略。已核验的 +24 清单含有 `FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_MEDIA_PLAYBACK` 和 `WAKE_LOCK`，来自固定 UGK 训练组件的媒体播放前台服务；+25 继续使用该组件，最终仍须以实际 AAB 合并清单确认。

你主动开始跟练后，训练服务帮助指导语音、提示音和会话计时在锁屏或切到后台时继续运行。组件会创建训练状态的持续通知和系统媒体会话，并在会话期间持有有超时上限的 CPU 唤醒锁；训练页面还会保持屏幕唤醒。你可回到 App 暂停或结束跟练；训练结束（允许结束语的短暂尾音）、离开播放器或页面销毁时释放服务，移除 App 任务时也会停止该服务。暂停或关闭声音不一定立即停止服务，它仍可能随当前训练会话保留。

这些能力用于当前训练的播放和运行，不录制麦克风或读取身体传感器。前台训练服务本身不实现训练记录上传；独立素材下载仍会产生第3节说明的网络数据。持续通知的展示取决于 Android 系统规则；没有申请广告或全屏通知能力。系统备份是独立的平台数据路径，最终权限和服务身份以交付 AAB 的合并清单为准。

本版本不请求相机、麦克风、定位、联系人、照片库、广泛文件访问、活动识别、身体传感器、健康平台、广告标识或通知运行时权限。若设备系统另行展示其自身提示，应以提示的具体来源为准。

## 6. 保留、删除和保护

训练结果和设置保存在当前设备的应用专用存储中，直至你清除应用存储或卸载 App。部分界面可能只展示最近若干条历史，隐藏旧记录不等于删除底层训练会话数据。清理动作素材缓存不会删除训练记录或安全确认状态。

没有开发者提供的云端账户或训练同步数据库，开发者无法替你远程删除设备上的记录。你可以在 Android 应用信息中清除存储，或卸载 App，删除本地应用数据；“新对话”和“清除记忆”各自只处理对应数据，不等于删除全部训练记录。操作前请确认需要保留的内容。清除或卸载本机 App 不保证同步删除系统备份；请在设备/平台备份设置中管理备份与迁移数据，重新安装时系统也可能恢复旧数据。

我们使用系统应用隔离和应用专用存储保护本地数据。设备解锁、系统备份以外的用户手动复制、越狱或其他系统安全变化不在 App 的控制范围内；任何存储或传输方法均不能保证绝对安全。

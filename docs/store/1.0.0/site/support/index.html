本地数据如何删除

在 Android 应用信息中清除 SmartFit 存储，或卸载应用，可删除本机应用数据。清除记忆、新对话、清理素材缓存只影响各自数据，不能替代清除全部存储。系统备份需在对应平台设置中单独管理，重装可能恢复旧数据。详见 隐私政策。

iPhone 本地数据删除

在 iPhone 上使用 iOS“删除 App”删除应用及当前设备上的相关数据。“卸载 App”会保留文稿与数据，“从主屏幕移除”只隐藏图标。系统备份需单独管理；恢复备份可能恢复旧记录。新对话、清除记忆和素材缓存清理各自只处理对应数据。详见iPhone 隐私说明。

训练与在线 AI

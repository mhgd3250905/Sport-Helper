English version

本政策说明 SmartFit 应用与本支持网站的数据处理方式。服务识别名称为 SmartFit；隐私与支持联系人：mhgd3250905@gmail.com。

iPhone 版本的适用说明

本政策同时适用于 iPhone 应用 com.ugk.smartfit，版本 1.0.0（25）。本地对话、安全问答、计划、训练结果、偏好、记忆、素材缓存、Cloudflare 网络请求和支持邮件的说明适用于两个平台。下文 Android 权限、前台服务、备份和删除操作仅适用于 Android；iPhone 的差异以本节为准。

iPhone 版本不配置在线 AI 密钥，原有 AI 入口和记忆设置仍可能可见，但使用本地规则与模板，不向 AI 服务上传对话或训练记录。无需注册账号，没有购买、订阅、广告或远程行为统计。App 不请求相机、麦克风、定位、联系人、照片库、广告跟踪或 HealthKit 权限，不采集身体传感器数据，不识别动作或评估姿势。训练期间的后台音频用于指导语音和提示音，不用于录音；WKWebView 通过设备内回环服务播放视频。

iOS 可能按照设备、账户及用户的备份设置，将符合条件的应用数据纳入 iCloud 或电脑备份，或迁移到其他设备。这是独立的平台功能，不是 SmartFit 提供的云同步数据库。本次未验证每一类文件的最终备份范围，不声称已关闭系统备份、数据永不离开设备或所有备份均采用相同加密方式。

请使用 iOS 的“删除 App”删除应用及当前设备上的相关数据。“从主屏幕移除”只隐藏图标，“卸载 App”保留文稿与数据，均不能替代删除应用数据。“新对话”“清除记忆”“清理缓存”仅处理各自数据。删除 App 不保证删除已有系统备份；请在对应平台设置中单独管理备份，恢复备份也可能恢复旧记录。开发者无法远程删除你设备上的本地记录。

1. 应用范围

SmartFit 提供对话式训练首页、动作库、本地规则和模板计划、训练播放器、训练记录与设置。无需注册账号。本版本未配置在线 AI 密钥，不启用在线 AI 请求；原有 AI 入口、引导和记忆设置可能仍然可见。没有接入广告、行为统计或远程崩溃上报服务。

2. 在设备上处理的信息

应用在设备的应用专用存储中保存以下信息，以提供本地功能：

  • 训练计划、训练名称、日期、时长、动作完成数量和训练会话结果，用于计划保存、训练和历史展示。
  • 近期对话、训练条件、安全确认问答及选择、最终确认与限制状态，用于原有规则交互和安全限制。
  • 在本机随机生成的设备 UUID、AI 记忆开关与本地记忆。本版本不通过 AI 请求发送这些数据；可以在设置关闭或清除记忆。
  • 主题、语音、提示音偏好，以及内置素材和本地播放缓存。

安全对话可能询问孕产、近期手术、运动限制、急性伤痛和心血管相关风险。问题及你选择的答案可能随近期对话保存，并非只保存最终状态。应用不通过相机、麦克风、定位、Health Connect 或身体传感器采集动作或健康测量值，不提供自动姿势识别。完成信息来自播放器的本地流程。

3. 应用网络、组件与系统备份

本版本不向开发者的 AI 服务上传对话、训练条件、计划、记录或设备 UUID。代码中的公开服务地址不代表本版本启用了请求。应用可按需通过 HTTPS 从 Cloudflare Pages 下载公开动作示范，保留的内置视频及已下载素材可由 127.0.0.1 / localhost 回环服务交给系统 WebView 播放。回环请求发生在同一设备内，不是互联网上传。素材请求包含所需公开文件路径和正常网络请求信息；Cloudflare 为传输、安全及基础设施运行可能处理 IP 地址、请求时间、浏览器或客户端及技术日志。应用不会在素材请求中附加对话、安全问答、训练计划、完成记录、AI 记忆或设备 UUID。Cloudflare 除了受托交付素材，也可能为其自身网络安全和服务运行处理衍生网络数据，例如流量模式和 IP 威胁评分，具体以其隐私政策为准。我们不利用 IP 地址推断用户位置。Cloudflare 的处理规则见其 隐私政策。应用使用 Flutter、系统 WebView、UGK 训练组件、本地偏好存储和音频组件。

系统备份与应用主动上传不同。本版本保留 Android 的默认备份行为。按照 Android 版本、用户启用的备份设置、账户和设备厂商规则，系统可能把符合条件的本地偏好、对话、训练记录和应用文件备份到用户的系统备份服务，或迁移到另一台设备。此过程由平台提供，不是 SmartFit 提供的云同步数据库；相关数据仍可能离开当前设备。备份的加密、保留、恢复和删除由对应平台规则管理，不能承诺所有设备上的备份都端到端加密，也不能承诺数据永不离开设备。

4. 使用、分享与支持邮件

应用中的本地数据用于对话、计划、跟练、历史、安全限制和设置。本版本不向开发者服务器上传这些数据，不出售这些数据，也没有广告或分析 SDK 向第三方自动发送这些数据。系统备份和迁移按上一节处理。

如果你主动通过外部邮件联系支持，支持联系人会使用你提供的邮箱、消息和附件解决问题。这不是应用自动上传。请勿发送密码、密钥或不必要的健康资料。问题处理完成后可通过同一邮箱申请删除你提供的支持资料；法律或必要的安全记录保留要求可能适用。

5. 权限与后台播放

INTERNET 支持 HTTPS 素材下载与本机回环媒体套接字；ACCESS_NETWORK_STATE 供媒体组件了解连接状态。FOREGROUND_SERVICE、FOREGROUND_SERVICE_MEDIA_PLAYBACK 与 WAKE_LOCK 用于用户主动开始的训练会话，支持指导语音、提示音、计时和亮屏。

训练组件可能创建持续训练通知和系统媒体会话，并在会话期间持有有超时上限的唤醒锁。用户可返回播放器暂停或结束。结束、离开播放器或页面销毁后释放服务，结束语可能有短暂尾音；移除任务时服务停止。暂停或静音不一定立即停止当前会话的服务。该服务不录音、不读取身体传感器、不上传训练数据。

本版本不申请相机、麦克风、位置、联系人、照片库、广泛文件访问、活动识别、身体传感器、健康平台、广告标识或通知运行时权限。

6. 保留、删除与安全

本地记录和设置保留到你清除应用存储或卸载应用。只显示最近历史不等于底层旧记录已删除。清理素材缓存不会删除训练记录；新对话或清除记忆也只处理相应数据。

你可在 Android 的应用信息中清除 SmartFit 存储，或卸载应用，删除设备上的应用数据。没有开发者云端账户或训练同步数据库，支持联系人无法远程删除你设备上的记录。清除存储或卸载不会保证删除系统备份；请在平台备份设置中管理这些副本，重装时系统可能恢复旧数据。

应用使用系统隔离和专用存储。设备解锁、手动复制、Root 以及系统安全变化可能影响保护，任何存储或传输方式都不能保证绝对安全。

7. 健身用途与未成年人

SmartFit 用于一般健身示范，不是医疗器械，不诊断、治疗、治愈或预防任何疾病。请向医疗专业人员咨询医疗建议、诊断和治疗；有孕产、伤病、术后、慢性病或其他风险时，开始训练前先咨询专业人员。本应用面向 13 岁及以上用户，不面向 13 岁以下儿童，不会建立儿童账户或投放广告。未成年人使用应遵循监护人与专业人员的指导。

8. 本支持网站

本网站为静态信息页面，不设置分析追踪器、广告或提交表单，不主动设置 Cookie。网站通过 Cloudflare Pages 提供，Cloudflare 为传输页面、保障安全和运行基础设施，可能处理访问 IP、请求时间、浏览器及请求信息，并按其规则保存技术日志。详情见 Cloudflare 隐私政策。点击邮件链接将打开你的邮件服务；该服务按其自身规则处理信息。

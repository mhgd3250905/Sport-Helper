## 1. HipLab 的历史设计参考（2026-10-19）

历史参考来自同一作者的 HipLab 配色、按钮、转场规范与真机图；原引用清单保存在[历史证据归档清单](../../deliveries/flat-release-20261026/retired-evidence/manifest.json)对应的设计文档原文中。HipLab 项目本轮未修改。

| 维度 | HipLab 的做法 |
|---|---|
| 配色 | **一个强调色**（jade：深色 `#3CCFA4` / 浅色 `#14A37B`，浅色小字用更深的 `#0D6E53` 保 AA）。其余全是中性灰阶：`background → surface → surfaceHigh → line`。橙 `tight`、红 `pain` 只用于语义（紧、疼），从不装饰。 |
| 明暗 | 两套同角色 palette，设置里「跟随系统 / 浅色 / 深色」。深色是石墨舞台，浅色是纸白 `#F4F5F3` + 白卡。媒体后来专门烘了浅色版本，保证视频框和页面底色一致。 |
| 字体 | 内置 Noto Sans SC（可变字重，OFL），全 App 一种字体。层级靠字号 + 字重：页面标题 20/w800，主按钮 18/w700，正文 15–16，元信息 11–13 muted。 |
| 间距 | 页边距 20；卡片内边距 16；组件间 8 / 12 / 16 / 24。 |
| 圆角 | 卡片 22，主按钮胶囊（stadium），底部弹层 28，缩略图 12–18；内外圆角同心。 |
| 卡片层级 | 历史参考为色调分层；旧绘制参数已退役，当前采用 353f146 三档实色与 1px 低对比边线。 |
| 按钮 | 金字塔：每屏**一个**实心强调色主按钮（无渐变、无阴影、无光晕）；次按钮 = surface 底 + line 描边；三级动作 = 文字按钮；工具按钮 = 色调圆盘。分段控件与开始按钮均采用实色，不使用旧材质实现。按下态统一：缩放 0.97 + 填充压暗 10%，100 ms 按下 / 180 ms 松开。 |
| 图标 | 自绘一套：24 格、1.75 笔画、圆端点圆角、描边/实心两态，替换所有 Material 图标。 |
| 动效 | 一组 token：fast 180 / medium 280 / slow 420 ms；页面进入 `Cubic(0.2,0,0,1)`；容器变换 500 / 420 ms `fastOutSlowIn`；**一次转场只有一个主运动**，去掉了所有 Hero；尊重“减少动态效果”。 |
| 媒体 | 视频/封面放在与渲染底色一致的“媒体舞台”上，圆角 22；首页英雄卡是深色舞台 + 左下白色大标题 + 右下「开始」圆盘；浮在视频上的标签用黑色半透明药丸。视频本身不加模糊、不加色。 |
| 留白 | 每屏信息量克制：首页一张英雄卡 + 一行选择器 + 两块磁贴；训练页“媒体 → 动作名 → 一句要领 → 计时环 → 下一个”。 |

一句话：**一个主色，色调分层，颜色而不是高度表达强调，一套字体一套图标一套动效。**

## 3. 2026-10-19 方案记录（历史）

### 3.1 保留什么

历史方案保留“主界面只有一段对话，漂在无边的空间里”：没有标题栏、没有边框、AI 回复计划卡片、开始后卡片长成整屏跟练。改变的是**落地方式**：采用集中 token 的实色分层。

### 3.2 深色 / 浅色：深色为默认，浅色可切换

**判定：默认「深空」（深色），设置里提供「浅色 · 白色无边空间」与「跟随系统」。**

理由：
1. **概念**：开哥确立的是“仿佛身处无边的宇宙”，深色是这个概念的原生形态；浅色版本用同一套结构，把星尘换成极淡的灰色微尘、天空换成纸白渐变，作为“白色无边空间”，同源而不是另一个 App。
2. **媒体**：现有 93 个动作的封面和视频都烘在 `#101013` 深底上。HipLab 的经验是视频框和页面底色不一致会显得像“贴上去的黑块”，他们专门重渲了浅色媒体。我们还没有浅色渲染，深色主题下视频与舞台天然融为一体；浅色主题下视频放在深色“媒体舞台”圆角框里（与 HipLab 首页英雄卡同一手法），可以接受但不是最佳。等 Pose-Hub 出浅色版本再评估是否把默认改为跟随系统。
3. **使用场景**：跟练时手机放在地上/桌上，深色更不刺眼、更省电（OLED）。
4. **成本**：两套 palette 同角色，所有组件只读 token，浅色是“免费”的；`SfPaletteScope` 切换时整树重建，不丢页面状态（照搬 HipLab `_PaletteScope`）。

| dust | `#DDE3F2`（低 alpha） | `#7D8781`（低 alpha） | 星尘 / 微尘 |
| background | `#0B0C10` | `#F4F5F3` | 普通页面 |
| surface | `#15171C` | `#FFFFFF` | 一级：卡片、输入框、抽屉、弹层 |
| surfaceHigh | `#1F2228` | `#EEF0EE` | 二级：卡片内可按的东西、chip、工具圆盘 |
| line | `#272A31` | `#E1E4E1` | 只在浅色上用作白卡发丝边 |

强调色选 jade 而不是保留珊瑚橙：①“UGK 家族”与 HipLab 同源；②绿色在深蓝黑上是冷静的“出发”信号，橙色在同一背景上过于喧闹，正是“新手程序员感”的主要来源；③jade 的明暗两套值和对比度在 HipLab 已真机验证过。休息/准备不再换蓝色，计时环在非训练阶段用中性色，训练中才用 accent。

**字体**：内置 Noto Sans SC 可变字重（OFL 1.1，取自 HipLab 同一文件，按 GB2312 + 代码与数据里出现过的字符子集化：17.8 MB → 4.1 MB，字重 100–900 全保留；子集外的生僻字由系统字体逐字回退）。字号 6 级：

| token | 字号/行高/字重 | 用途 |
|---|---|---|
| display | 28 / 1.25 / w700 | 完成页标题 |
| title | 20 / 1.3 / w700 | 计划标题、页面标题、动作名（跟练 24） |
| headline | 17 / 1.35 / w600 | 区块标题、弹层标题 |
| body | 16 / 1.6 / w400 | 对话正文 |
| callout | 15 / 1.4 / w500 | 列表行、chip、卡片内按钮 |
| label | 13 / 1.4 / w400 muted | 元信息、剂量 |
| caption | 12 / 1.4 / w400 faint | 时间标记、脚注 |

**间距**：4 的倍数（4 / 8 / 12 / 16 / 20 / 24 / 32），页边距 20（对话列表 16，让卡片多 8pt 宽）。
**圆角**：8（小标签）/ 12（列表缩略图）/ 16（内部方块、chip 行、输入框）/ 22（卡片、气泡、媒体）/ 28（弹层、抽屉）；嵌套时内圆角 = 外圆角 − 内边距。
**阴影**：深色无；浅色只给一级卡片 `#1D2B25 7% blur24 y8` + `#000 3% blur2 y1`。全 App 无彩色光晕。
**动效**：fast 180 / medium 280 / slow 420；按下 100 / 松开 180、缩放 0.97；消息出现 360 ms 淡入 + 上移 12px；卡片 → 跟练容器变换 500 / 420 ms `fastOutSlowIn`，对话只变暗不缩放。

### 3.4 按钮金字塔（`lib/ui/theme/widgets.dart`）

| 层级 | 组件 | 样式 | 出现位置 |
|---|---|---|---|
| 主 | `SfPrimaryButton` / 强调色圆盘 | accent 平涂，无阴影无渐变 | 计划卡片「开始」、跟练暂停/继续、完成页「完成」、发送（有字时） |
| 次 | `SfSecondaryButton` | 深色 surfaceHigh / 浅色白底 + line | 弹窗的取消类、少量并列选择 |
| 三级 | `SfTextAction` / `TextButton` | 图标 + 文字，无容器 | 卡片「保存」「详情」、展开全部、抽屉入口 |
| 工具 | `SfCircleButton` | 色调圆盘（浅色加发丝边） | 关闭、上一个、跳过、抽屉里的 ▶ |

规则：**每屏最多 1–2 个强调色元素。** 对话里只有最新那张计划卡片的「开始」是强调色；抽屉里的 ▶ 改为工具圆盘（强调色图标），不再是三颗橙球。旧材质实现已退役——我们没有分段控件，也没有坐在媒体舞台之外需要分离的英雄按钮；计划卡片的「开始」圆盘坐在封面舞台上，用纯色 + 1px 接触影即可。

### 3.5 逐屏方案

**对话首页**
- 背景：天空两色渐变 + 一团极淡的冷色光（深色）/ 无（浅色）；星尘 48 颗、更小、更暗、只有最近的 6 颗带极小光晕；漂移速度减半。
- 助手消息：`assistantBubble` 色调气泡（深色 88% 不透明的 surface，浅色白卡 + 阴影），无描边、无模糊；正文 body 16/1.6。
- 用户消息：`userBubble`（比 surface 亮一档的中性灰），右对齐，不再用彩色——强调色留给“要做的事”。
- 选项：气泡内 chip，surfaceHigh 底；选中 = accentSoft 底 + accentText 字 + w600；已失效的变 faint。
- 时间标记 caption；顶部内容淡出到天空色。

**计划卡片（重点）**
1. **封面舞台**：卡片顶部 8pt 内嵌一块深色媒体舞台（圆角 14，宽高比 16:11），第一个动作的封面居中铺满；底部 55% 高度从透明渐变到舞台色，**标题 22/w700 白字 + 元信息**压在左下（HipLab 英雄卡手法）。
2. **主按钮**：舞台右下角 64pt 强调色「开始」圆盘（三角图标 + “开始”），全卡唯一强调色；按下缩放 0.97。
3. **元信息**：舞台内一行 `14 分钟 · 10 个动作 · 徒手 · 入门`，13/w500 白 72%；不再塞进正文区。
4. **动作列表**：每行 36pt 缩略图（圆角 10，舞台色底）+ 动作名 15/w500 + 剂量 13 muted 右对齐，行高 48；默认显示 4 个，「展开全部 10 个动作」为三级文字按钮。
5. **页脚**：左「保存」（书签图标，已保存时实心 + accentText「已保存」），右「详情」（chevron），都是三级文字按钮；“已按你的情况调整 N 处”放在列表下方 caption。
6. 卡片本身：surface 色调，圆角 22，浅色加发丝边与淡阴影。

**快捷建议与输入框**
- 建议 chip：高 36，surfaceHigh（浅色白底 + line），callout 14 muted；横向滚动，左右留白 16。
- 输入框：surface 胶囊，圆角 26，高 52；左侧书签图标（自绘），右侧 36pt 发送圆：有字时 accent 实心 + onAccent 箭头，无字时透明 + faint 箭头；无外发光。

**已存计划抽屉**
- 背景 surface（不透明，无模糊无描边），右侧圆角 28；标题 title 22，副标题 label。
- 每行：surfaceHigh 色调块（圆角 16），52pt 封面（圆角 12），名称 callout w600，元信息 label；▶ 为 40pt 工具圆盘 + accentText 三角；⋯ 菜单 muted。
- 底部入口：图标 20 muted + 标签 callout + 提示 caption，与列表之间 24pt 间距 + 一条 surfaceHigh 分隔。

**跟练页**（结构参照 HipLab 训练页）
- 顶栏：关闭工具圆盘 44 · 中间“区块名 + 进度条”（label + 3pt 圆角条，accent）· 右侧 `1/10` 计数（tabular）。

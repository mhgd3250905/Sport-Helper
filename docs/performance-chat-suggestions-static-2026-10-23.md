# +21：所有聊天建议条静态仿玻璃

本轮授权将建议条静态仿玻璃扩展到所有聊天会话，输入框仍保留原真玻璃。星尘、SDK、预热（关闭）、列表结构和其他渲染参数不改。含计划卡会话原本就使用此策略，所以本轮不重跑已达标的计划卡两格。

## 改动与采样标识

`ChatHomePage` 对所有内容采用同一建议条策略；`isPlanContext` 仍按实际计划卡内容记录，不再作为普通聊天恢复真玻璃的条件。建议条沿用已实现的静态底色、细描边与轻阴影；输入框默认 blur、饱和度和质量策略保持原值。

内测当前默认聊天格改记 `chat_suggestions_static__longChatScroll`，直接运行真实页面，不用实验 scope 覆盖其默认。历史 `chat_baseline__longChatScroll` 保留显式全真玻璃策略用于兼容旧报告，不将新默认误标成旧基线。

仅为用户授权的条件补采增加 `chat_suggestions_static_input_blur_1_2__longChatScroll`：浅色输入框绝对 blur 为 1.2，建议条仍静态，其他材质和参数不变。该值只在内测输入框生效，正式默认不变，采样退出后恢复。深色按钮禁用，记录器和分析器也拒绝将深色该格判为有效。生产版不含内测入口或记录器。

每帧条件、实际角色材质及进入窗口继续记录；新配置使用独立有界槽位，不写逐帧文件。旧九格实验及原始报告仍可读取。

3. 若浅色默认仍未达标，追加一次“补采浅色聊天 · 输入框模糊 1.2”，保留默认格与补采格分别统计并导出；不把补采成绩冒充默认成绩，不继续优化代码。

## 浅色首份记录：保留原始数据，排除 120Hz 验收

开哥提供的 `SmartFit-performance-20261023T150219567757Z.json` 已 [按原字节归档](reports/performance-chat21-light-20261023T150219567757Z.json)，28502 bytes，SHA-256 `fd302e50a7671a7adb207ddedfbc3b20cd3b4ead3da3859feee37119c8b2e49a`。源码、版本、场景、静态建议条、输入框原 blur 1.5/saturation 1.1、星尘开启及预热关闭均正确，结构和进入窗口校验无问题。

但该格始终记录为 **60Hz / 16.666667ms 预算**，与上一轮 120Hz / 8.333333ms 条件不一致。稳态 Raster 平均 4.073399ms、P90 4.863ms、P99 5.887ms、最差 16.160ms，超预算 0/3615 仅针对 16.667ms。最差帧已经超过 8.333ms，不能将这份报告的“0”解释为 120Hz 超预算为 0，也不能恢复精确的 8.333ms 超预算数量，因为导出未保留逐帧数据。

该格约 30.022 秒收到 3615 个稳态引擎帧，与 60Hz 标签存在疑点，但引擎回调数量不能直接证明屏幕物理刷新率。独立只读审计结论一致：本格不作为 120Hz 合入证据，不据此计算跨版本收益。首次进入 Raster 最差 19.573ms 仍单列，不参与稳态门槛。

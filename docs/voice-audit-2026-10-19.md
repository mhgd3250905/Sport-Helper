# 语音播报审计与重做（2026-10-19，`feat/drill-packs`）

**目标**：把 HipLab 10-18 的语音修复（播放链路 + 素材后处理 + 逐条检测，见 HipLab `docs/voice-audit-2026-10-18.md`）落到 SmartFit，并让每个动作有自己完整的台词，装进动作小包（[drill-pack-spec.md](drill-pack-spec.md)）。

**结论**：素材按 HipLab v4.1 链路全部重做，**695 条 0 失败**（旧 270 条有 60 条失败，全是响度不一致）；播放链路已与 HipLab 最新版一致；跟练时间线改为按小包台词的实际解码时长排，保证句子不重叠、不被倒数切断。

## 1. 旧素材的问题（M2，270 条）

旧 `build_voice.py`：`silenceremove` 裁首尾 + 单遍 `loudnorm=I=-16:TP=-2:LRA=7`（动态模式），manifest 用 ffprobe 容器时长。用同一个检测工具（`audit_voice.py --legacy … --raw`，阈值与 HipLab 相同）逐条测：

- **60 / 270 不通过，全部是响度偏离 -16±1 LUFS**：整体 -19.3 … -11.9 LUFS（跨 7.4 LU）。56 条偏轻（动作名、要领多在 -17 … -19，如 `ex.n-wide-fold` -19.3、`p.switch_left` 换左侧 -19.2），4 条偏响（单字数字和"第"：`p.di` -11.9、`n.1` -12.5、`n.5` -12.6、`n.2` -13.3）——也就是**倒数数字比口令和要领响 5–7 dB**，正是"忽大忽小"。
- 没有截断、没有句中被剪、真峰值都 ≤ -1.6 dBTP、manifest 与实际解码最多差 23 ms。SmartFit 旧素材的单遍 loudnorm 比 HipLab 旧版温和，所以问题只在响度。

## 4. 时间线：按小包台词排、不重叠、不切长句

`SessionScript` 改为用小包台词和每条的 `ms`（实际解码长度）排时间线：

- **一个阶段一张时间线**：先放固定时刻的口令（开始、还剩十秒、过半、倒数 3-2-1、每次计数），再把可伸缩的句子（预告、介绍、要领、休息提示）按顺序**只放进完整放得下的空档**（前后各留 0.35 s），放不下就不说，**绝不截断**；倒数前额外留 0.5 s 余量，给会话激活/加载的延迟。
- 准备阶段：欢迎 + 全程分钟 → 第一个动作 `intro` → 剂量 → `cue1`。
- 动作之间休息：一组结束提示音 + 上个动作 `finish`（"X，完成"）+ 休息 N 秒 → "下一个动作" + `intro` → 剂量 → `cue1`（空档够再说 `cue2`）。
- 同一动作组间休息：很好/休息 N 秒 → 第 N 组 / 最后一组 → 该动作 `rest` 台词。
- 计时动作进行中：开始 → `cue1…cue3` 依次塞进空档（过半、还剩十秒、倒数之间），第二侧开始后说 `side_switch` 代替 `cue1`。
- 次数动作：开始 → 按视频节奏逐次计数（公共包数字）；要领在之前的预告/组间休息里说，不和计数抢。
- 换侧阶段只有 5 s：只说公共包"换左侧"+ 倒数，单侧专属的 `side_switch` 放到第二侧开始后。

测试 `test/voice_session_test.dart` 新增：遍历全部 13 个模板生成的完整课程，每个阶段检查**任意两句不重叠**、**每句在阶段结束/倒数开始前说完**、引用的每个音频都存在。

## 5. 需要本机复听 / 实测

自动检测不能代替人耳和真机音频行为：

1. **文案听感（最重要）**：intro / rest / side_switch / finish 是按元数据固定句式生成的，挑 10 个左右动作完整听（建议：徒手深蹲、单腿臀桥、哑铃罗马尼亚硬拉、靠墙静蹲、前臂平板支撑、90 90 后腿主动抬起、仰卧蝴蝶主动开合、沙发拉伸、扶椅站姿股四头肌拉伸、死虫式），不顺的直接改 `pack.json` 的 `text.zh`，按 [drill-pack-spec.md](drill-pack-spec.md) §4 流程重跑。
2. **音量一致性**：倒数数字（以前偏响 5–7 dB）、"换左侧"（以前 -19 LUFS）、长要领之间音量是否接近。
3. **不重叠/不截断**：跑一套计时为主的模板（如"运动后拉伸"）和一套次数为主的（如"哑铃全身力量"），听预告和要领是否完整、倒数是否准点、计数是否跟视频节拍。
4. **背景音乐 ducking、来电/拔耳机中断、锁屏**：播放链路与 HipLab 相同，按 HipLab 清单复测一遍 Android。
5. 包体：语音 14.9 MB（695 条），视频 + 封面约 11 MB，小包合计约 26 MB；如需缩小可在 HipLab 验证后统一降码率。
